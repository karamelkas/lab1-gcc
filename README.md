# Лабораторная работа №1

**Тема:** Командная строка и особенности использования набора компиляторов и утилит GCC

## Вариант 1

1. **task1.c** — вычисление произведения n сомножителей вида 2/1 · 2/3 · 4/3 · 4/5 · ...
2. **task2.c** — формирование массива из уникальных элементов массива M(25)
3. **task3.c** — проверка массива A(20) на строгое возрастание

## Компиляция

    gcc task1.c -o task1.exe
    gcc task2.c -o task2.exe
    gcc task3.c -o task3.exe

## Запуск

    task1.exe
    task2.exe
    task3.exe
